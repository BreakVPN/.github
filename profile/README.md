## About BreakVPN

We believe using a VPN should be simple.

BreakVPN is built around a straightforward experience: choose a location, connect, and you're ready to go — without unnecessary complexity.

Our infrastructure is designed with performance, stability and privacy in mind.

## What we focus on

- 🔒 **Privacy** — designed to minimize unnecessary data collection
- ⚡ **Performance** — fast infrastructure and optimized network routes
- 🌍 **Global network** — multiple locations for different use cases
- 📱 **Cross-platform** — access from your favorite devices
- 🎨 **Clean experience** — simple configuration and optional custom themes
- 🛠️ **Reliable infrastructure** — continuously maintained and monitored
